MathTutorApp - Руководство для разработчиков
📝 Описание проекта
Проект MathTutorApp представляет собой JavaFX-приложение для обучения математике с админ-панелью.

🛠 Настройка окружения
Требования
Java JDK 11+
Maven 3.6+
Git 2.30+

Установка
Клонируйте репозиторий:
git clone https://github.com/kiarin17/MathTutorApp.git
cd MathTutorApp

Настройте Git:
git config --global user.name "Ваше Имя"
git config --global user.email "ваша@почта.com"

🔧 Работа с Git
Основные команды

# Получить последние изменения
git pull origin master

# Проверить статус изменений
git status

# Добавить все изменения
git add .

# Создать коммит
git commit -m "Описание изменений"

# Отправить изменения на сервер
git push origin master

Рабочий процесс
Перед началом работы:
git pull origin master

Создайте новую ветку для задачи:
git checkout -b feature/название-фичи

После завершения работы:
git add .
git commit -m "Реализована фича X"
git push origin feature/название-фичи
